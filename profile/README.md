# infiniti-mainline

Mainline Linux and U-Boot for the **OnePlus 15** (CPH2749, Qualcomm
SM8850 _Kaanapali_).

- [`linux`](https://github.com/infiniti-mainline/linux): kernel with patches for OnePlus 15
- [`u-boot`](https://github.com/infiniti-mainline/u-boot): u-boot for chainloading linux

Goal: Maintain and upstream a minimal set of patches to support mainline Linux on the OnePlus 15.
